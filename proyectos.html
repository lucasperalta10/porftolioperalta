Sistema de Gestión

ControlAR

Sistema de gestión de stock e inventario diseñado para negocios pequeños, pensado para agilizar el control diario de mercadería y la atención en mostrador.

Problema que resuelve

Reemplaza el control manual en papel o planillas dispersas, centralizando el registro de productos, la consulta rápida de precios en mostrador y las alertas de reposición cuando el stock es bajo.

Tecnologías utilizadas

  • HTML5
  • CSS3
  • JavaScript
  • Base de Datos / SQL

Videojuego

NightWatch

Videojuego de terror y supervivencia inspirado en Five Nights at Freddy's, centrado en la tensión ambiental, la vigilancia y la gestión de recursos durante la noche.

Problema / Desafío que aborda

Ofrecer una experiencia de terror interactiva con mecánicas de monitoreo en tiempo real, manejo de estados del juego, eventos temporizados y respuesta visual y sonora para mantener la inmersión del jugador.

Tecnologías utilizadas

  • Python
  • Lógica de Videojuegos
  • Git / GitHub
