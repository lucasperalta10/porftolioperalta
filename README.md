# Portfolio Personal — Lucas Peralta

Sitio web estático de portfolio personal desarrollado con **HTML5**, **CSS3** y **JavaScript Vanilla**, diseñado bajo un enfoque *mobile-first* y sin dependencias ni procesos de compilación.

**Demo en vivo (GitHub Pages):**  
https://lucasperalta10.github.io/porftolioperalta/

---

## Estructura del Proyecto

```text
portfolio/
├── index.html          # Página principal (Inicio, Proyectos Destacados, Reseñas, Sobre Mí, Conocimientos, Educación y Contacto)
├── proyectos.html      # Vista detallada de proyectos
├── css/
│   ├── reset.css       # Reset CSS y soporte para prefers-reduced-motion
│   └── styles.css      # Variables de tema, layout responsive y estilos de componentes
├── js/
│   ├── main.js         # Navegación móvil, controles de ventana, reloj, animaciones y validación del formulario
│   └── terminal.js     # Consola / terminal interactiva del sistema
└── assets/
    ├── icons/          # Iconos de tecnologías y capturas de proyectos
    └── img/            # Recursos gráficos locales
```

## Ejecución Local

No requiere instalación de paquetes ni pasos de compilación:

1. Abre `index.html` directamente en tu navegador, o
2. Inicia un servidor estático local desde la raíz del proyecto:
   ```bash
   python -m http.server 8000
   ```
   Luego ingresa a `http://localhost:8000`.
